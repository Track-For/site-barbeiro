# Atelier 27

MVP fictício de uma barbearia premium construído com Vue 3, Vite, GSAP e ScrollTrigger.

## Executar

```bash
npm install
npm run dev
```

Build de produção:

```bash
npm run build
npm run preview
```

Todo o nome, endereço, preços, profissionais, avaliações, contatos, depoimentos e imagens deste projeto são fictícios.
